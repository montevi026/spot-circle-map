# スポットサークルマップ

位置ゲーム攻略用に、地図上のスポットを中心とした半径 N m の円を表示する Web サイトです。
GitHub Pages で公開しています。

## 構成

```
server.py            ローカル編集用サーバー（Python 3 標準ライブラリのみ）
start-edit.bat       ダブルクリックで編集モード起動
publish.bat          ダブルクリックで公開サイトへアップロード
docs/                ← GitHub Pages で公開されるフォルダ
  index.html / app.js / style.css
  data/events.json   イベント・スポットのデータ（編集すると自動で書き換わる）
```

## 編集 → 公開の流れ

1. `start-edit.bat` をダブルクリック（または `python server.py`）
2. ブラウザで `http://localhost:8000/` が開き、「編集モード」と表示されます
3. 「＋ イベント追加」… イベント名・デフォルト半径・表示色を登録
4. イベントの ▼ を開いて「＋ スポット追加」
   - 名称で検索 → 結果を選択（OpenStreetMap / Nominatim で検索）
   - または地図をクリックして場所を指定。マーカーはドラッグで微調整可能
   - 半径はイベントのデフォルト値が入るので、必要ならスポットごとに変更
5. 保存すると `docs/data/events.json` が更新されます（この時点ではまだローカルのみ）
6. 編集が終わったら、サイドバー上部の **「公開サイトへアップロード」** ボタンを押す
   （または `publish.bat` をダブルクリック）。git commit & push され、1〜2 分で公開サイトに反映されます

未アップロードの変更があると、ボタンの横に「未アップロードの変更あり」と表示されます。
`http://localhost:8000/?view` を開くと、公開時と同じ閲覧モードで確認できます。

## 公開サイトについて

公開サイトには `server.py` がないため API が存在せず、自動的に閲覧専用になります。

## 閲覧時の機能（設定はブラウザの localStorage に保存）

- イベントごとの表示 ON/OFF（チェックボックス）
- スポットの「攻略済」切り替え（地図のスポットをタップ → ボタン、または一覧のチェック）
- スポット名の常時表示 / 攻略済スポットを隠す
- ◎ ボタンで現在地表示
